# Embedded font information

The SVGs embed an ASCII-only WOFF subset derived from DejaVu Sans, renamed **Profile Sans**. It replaces the previously embedded Segoe UI font; no Segoe UI font data remains in the SVGs.

DejaVu fonts are derived from Bitstream Vera. The Bitstream Vera font license permits modification and redistribution subject to its conditions; DejaVu changes are in the public domain. The complete upstream copyright, permission notice and additional bundled font notices are preserved in [licenses/DejaVu-LICENSE.txt](licenses/DejaVu-LICENSE.txt).

Keep this notice and the complete license when redistributing these SVGs. No font download is requested at runtime.
